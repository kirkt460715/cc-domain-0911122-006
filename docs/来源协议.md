# 试验分页接口
python3 -m lab.provider 启动服务。POST /graphql 接受 operationName、query 和 variables。演练服务只分派固定操作，不实现任意 GraphQL 查询执行器。OpenBatch 返回 revision；Experiments 的变量为 revision、after；Measurements 另需 experiment。after 初始为 null，后续传 pageInfo.endCursor。query 可使用对应操作名的合法文本，fixture 不解析其选择集。实验 expA、expB 各有两页测量，value 是精确十进制文本，group 是 A/B。expA 第二页首次返回 data 与 errors，错误 path 指明缺失分支。extensions.remainingCost 递减。POST /control {"expire":true} 淘汰旧批次。它是只读来源协议，不创建 Trialvault 数据版本。
