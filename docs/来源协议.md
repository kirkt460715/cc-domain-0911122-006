# 试验分页接口

python3 -m lab.provider 启动服务。POST /graphql 接受 operationName、query 和 variables。演练服务只分派固定操作，不实现任意 GraphQL 查询执行器。OpenBatch 返回 revision；Experiments 的变量为 revision、after；Measurements 另需 experiment。after 初始为 null，后续传 pageInfo.endCursor。query 可使用对应操作名的合法文本，fixture 不解析其选择集。实验 expA、expB 各有两页测量，value 是精确十进制文本，group 是 A/B。expA 第二页首次返回 data 与 errors，错误 path 指明缺失分支。extensions.remainingCost 递减。POST /control {"expire":true} 淘汰旧批次，{"credit":N} 给服务端预算充值。它是只读来源协议，不创建 Trialvault 数据版本。

Provider 构造参数：cost 为初始请求预算（默认 50），fail_attempts 为 expA 第二页连续失败次数（默认 1，fail_once 保留兼容）。

# 冻结批次采集（Trialvault 侧）

trialvault/harvest/ 实现面向该接口的采集入口，动作经 python3 -m trialvault --root DIR run action.json 调用：

- harvest_open：harvest、endpoint、batch、dataset、schema_version。打开采集任务，校验数据集与 schema 已登记；同 ID 重复打开需身份一致。
- harvest_run：harvest、endpoint、max_requests、budget_credit、retry_failed_branches。推进采集；状态落盘于 vault/harvests/<id>/，可随时重启续跑。
- harvest_status / harvests：查看单个或全部采集任务。
- harvest_publish：harvest、request、classification、scopes、expected_version。全部取齐后经既有 ingestion 入库，产生数据集版本。
- harvest_lineage：harvest、measurement。从数据行追到实验、原始响应页 artifact 与请求参数。

行为要点：

- 外层实验列表与每个实验的测量列表各自分页，外层 hasNextPage=false 不代表内层取完；内层进度按实验分别保存。
- HTTP 200 同时携带 data 与 errors 时，错误按 path 归到对应实验/测量分支，成功分支继续；无法归类的错误使任务中止，绝不把未知范围当作空数组。
- 外层游标、各实验内层游标与冻结 revision 严格分离；同一测量 ID 重现时核对内容摘要，不一致即中止；页尾游标无进展或循环明确中止。
- 预算取本地充值与服务端 extensions.remainingCost 的严格下限；耗尽或收到 429 时保留可恢复状态，不无限重试。budget_credit 充值后续跑。
- 冻结 revision 失效（extensions.revision 变化或 EXPIRED 错误）时任务进入 expired：旧结果可查看、可追溯，但不能与新 revision 拼成完整数据，也不可恢复运行。
- 重试只补缺失或失败分支，已取齐部分不产生新版本；publish 幂等，同 request 重复调用复用结果。expected_version 与数据集当前 head 不一致时按 conflict 报出。

python3 -m trialvault.harvest_demo 演示：expA 第二页失败、expB 先取完、重启补齐、expected_version 冲突、行级谱系追溯、冻结 revision 过期与发布后导出。
